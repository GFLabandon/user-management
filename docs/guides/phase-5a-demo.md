# 5A 演示路径

更新：2026-10-09。对应 5A.1 账号关联选择、5A.2 错误反馈、5A.3 操作记录查询。本机已验收并随 PR #1 合并，main CI 通过；这是虚构资料演示，不代表真实高校交付。

## 准备

按 [README](../../README.md#快速运行)启动独立的默认 `demo` 环境，用 `admin / demo-admin-pass` 登录；只读账号为 `viewer / demo-viewer-pass`。不要将演示账号用于部署。演示使用内存 H2，重启清空数据；下面的变更仅在这个临时环境中执行。

## 一条完整路径

1. **登录 → 查询档案**：在“辅导员档案”输入 `DEMO-001`，查询并打开“示例张老师”详情。说明业务档案与登录账号分开，建档不会自动产生账号。
2. **编辑冲突**：在两个标签页打开同一档案的编辑页。第一个标签页修改备注并保存；第二个标签页填入不同备注后保存。第二次得到 409 冲突提示，输入保留、旧表单保存按钮禁用；点“重新打开最新记录”查看先前保存的内容。
3. **账号关联**：进入“账号管理”，编辑演示只读账号；按 `DEMO-001` 搜索，核对姓名、工号和院系，选择后保存。密码留空。列表会显示关联档案，服务端仍限制一份档案只能关联一个账号。账号信息改变后，该账号已有会话会失效。
4. **查询操作记录**：回到刚才的档案详情，点击“查看操作记录”，自动按该档案的类型与编号筛选。也可从账号或院系列表点击对应行的同名入口；账号入口查看账号自身的记录。需要进一步缩小时，再填写操作者 `admin` 和页面所示时区下的操作日期。先查全部结果，再选“失败”，可定位刚才的过期提交；恢复“成功”可找到保存事件。事件代码未变，页面展示中文解释。
5. **翻页与恢复**：选择每页 10 条，在有足够记录时点击下一页或末页，筛选保持。改成不存在的账号会显示空结果；把开始日期设为结束日期之后会显示可修改的错误，已填条件保留。点“重置”回到默认查询。
6. **权限边界**：退出后以 `viewer` 登录，可查看档案，不能访问账号管理或 `/audit`。拒绝页面提供返回档案列表入口。

默认演示启动只有少量操作记录，不自动生成上百条。超过 100 条的分页场景由自动化测试和独立 HTTP 演示数据验证；不要把截图中的验收记录数量当作项目真实用户规模。

## 讲解时保留的边界

当前只有管理员／只读两种固定角色，没有院系级数据隔离。审计是已记录的操作结果，不包含字段前后值、异常堆栈或防篡改保证；部分失败只能定位到“变更未完成”，不能据此推断更细的业务原因。时间按页面注明的数据库会话时区查询，不自动转换为浏览器时区。分页是实时列表，新增记录后跨页位置可能变化。
