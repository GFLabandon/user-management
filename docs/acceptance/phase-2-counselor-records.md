# 第二阶段：辅导员档案业务验收

日期：2026-09-06。开发基线：第一阶段提交 `a916d1d`。本地分支：`codex/counselor-records`，本阶段已作为独立本地提交保存，尚未推送；提交号见 Git 历史。

## 本轮结果

独立 Counselor 档案，工号唯一、姓名允许重复、院系与任职状态维护、稳定分页筛选、版本冲突检查、状态历史、专用表单绑定及 Flyway 迁移已实现。旧角色不再出现在档案表单中，旧关系保留在数据库供核对。

写入档案和状态记录位于同一 Service 事务中。图片先存入独立目录；数据库失败或版本冲突清理新文件；成功提交后清理旧图。文件复制中断也尝试清理部分文件，清理失败写日志。它仍不具备数据库与文件系统的原子提交或持久化补偿队列。

## 自动化检查

环境：Temurin 17.0.20、Maven Wrapper、Spring Boot 3.5.7、Flyway 11.7.2、H2。命令：

```bash
./mvnw --batch-mode --no-transfer-progress clean verify
```

结果：26 项测试通过，0 失败、0 错误、0 跳过，JAR 构建成功。

| 范围 | 证据 |
| --- | --- |
| 档案与页面 | 同名允许、工号大写及唯一、表单校验、非法状态、主键／照片路径不可绑定、旧路由兼容与旧写入退役 |
| 登录保护 | 新档案和院系路径匿名访问跳登录；登录 Session 与退出失效 |
| 检索与分页 | 工号／姓名与状态／院系组合、稳定页结果、越界与每页上限、通配符按字面搜索、SQL 注入样例不扩大结果 |
| 查询数量 | MyBatis StatementHandler 实测：小页和大页均为 2 条 SQL，计数 + JOIN 分页，无逐行院系查询 |
| 状态与版本 | 停用、恢复、操作者与历史；过期修改／停用不能覆盖；编辑请求必须带版本 |
| 院系规则 | 引用阻止删除、停用阻止新关联、原有停用院系关联可保留编辑、院系版本冲突 |
| 文件补偿 | UUID 文件存储、类型拒绝、单文件清理、版本冲突只清理失败请求的新图、流中断清理部分文件 |
| 事务原子性 | 历史写入失败会回滚新档案，或回滚状态与版本更新 |
| 迁移 | 空库无业务种子、未接管非空库拒绝、缺少映射先停止、原字段及旧角色保留、自增 ID 正确、重复启动不重复迁移 |

错误路径测试会主动触发迁移异常和数据库约束异常；日志中的这些预期异常不代表测试失败。以 Surefire 汇总为准。
