# 档案列表条件保留

日期：2026-10-05。基线 `d3269f7` 的[合并后 CI](https://github.com/GFLabandon/user-management/actions/runs/37208401260) 已通过。

## 行为

此前按关键词、院系、状态筛选后打开档案，再点击“返回档案列表”或编辑页“取消”，会回到默认列表。现在从列表进入详情、编辑或新增时，携带该列表的关键词、院系、任职状态、页码和每页条数。保存、停用、表单校验失败和编辑冲突均保留这些条件。

条件属于当前页面，通过链接和隐藏表单字段传递，不写入 Session，因此多个标签页互不覆盖。直接打开不带条件的档案网址，仍返回默认列表；列表“重置”和主导航“辅导员档案”也保留清除条件的入口。

返回时重新查询当前数据。若修改后记录不再匹配条件，记录会从原列表消失；原页码超出范围时，现有分页逻辑自动回到有效页。本功能不保存结果快照或页面滚动位置。

## 实现边界

- 只接受已知筛选字段，由固定 `/counselors` 路径生成返回地址，不接受任意 `returnUrl`。
- 关键词限制仍为 100 字符；页码／条数规范化，非法类型返回 400。中文、空格、加号、百分号等按 URI 编码传递。
- 业务表单仍使用原字段白名单；权限、版本检查、SQL、索引、V1–V4、11 张表和备份格式均未改变。
